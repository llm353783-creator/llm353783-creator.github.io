# 凯文·德布劳内 · 个人主页

一个支持中英文切换的个人主页静态网站，可直接部署到 GitHub Pages。

## 文件结构

```
de-bruyne-homepage/
├── index.html        # 单文件网站（含全部样式与脚本）
├── assets/           # 图片素材
└── README.md
```

## 页面与功能

- **首页**：自我介绍（出生、位置、俱乐部与国家队的完整履历概述）、核心特点、基本信息
- **图集**：影像与文字（点击图片可放大预览）
- **生涯**：俱乐部生涯时间轴（亨克 → 切尔西 → 沃尔夫斯堡 → 曼城 → 那不勒斯）+ 国家队生涯时间轴
- **数据**：2025-26 赛季数据（出场 21、进球 5、助攻 4、场均评分 7.04）、生涯里程碑、俱乐部荣誉、关键赛季进球与助攻柱状图
- 右上角「EN / 中文」一键切换语言，选择会被浏览器记住
- 自适应手机 / 平板 / 电脑

## 内容说明

- 人物信息、生涯经历与赛季数据来自页面所有者提供的文字材料
- 「关键赛季 · 进球与助攻」图表数据来自生涯记录中的部分赛季，进球 / 助攻为当季合计，口径随赛季来源略有差异
- 需要修改文字时：中文在脚本区 `I18N.zh`，英文在 `I18N.en`，HTML 中的默认文本需同步更新
- 新增图集图片：将图片放入 `assets/`，在 `.gallery-grid` 中复制一个 `.g-item` 并把 `src` 写成相对路径

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（Public 或 Private 均可）
2. 将 `index.html` 和 `assets/` 文件夹上传到仓库根目录（保持相对路径不变）
3. 进入仓库 **Settings → Pages**
4. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，点击 **Save**
5. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可

> 提示：若仓库名为 `<用户名>.github.io`，访问地址为 `https://<你的用户名>.github.io/`
